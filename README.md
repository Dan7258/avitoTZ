## Как запустить проект

### Через Makefile

```bash
# Клонируем репозиторий

# Собрать образы и поднять всё одной командой
make              # выполнит make build + make up

# Или по отдельности:
make build        # docker-compose build
make up           # docker-compose up -d

## Цели мейкфайла   
| Команда               | Описание                                                                                        |
|-----------------------|-------------------------------------------------------------------------------------------------|
| `make` или `make all` | **Основная команда** — собирает образы и запускает сервис с БД                                  |
| `make build`          | Только пересобирает Docker-образы                                                               |
| `make up`             | Поднимает уже собранные контейнеры                                                              |
| `make down`           | Останавливает и удаляет контейнеры                                                              |
| `make clean`          | Полная очистка: контейнеры + volume с БД + все образы                                           |
